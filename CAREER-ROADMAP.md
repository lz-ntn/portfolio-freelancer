## ⚠️ Erros Comuns a Evitar

1. **Preços demasiado baixos** → $5/h desvaloriza o trabalho
2. **Aceitar tudo** → projetos mal pagos consomem tempo que podias usar para clientes melhores
3. **Sem contrato** → usar sempre um contrato simples (enviar o Guia de Proposta)
4. **Entregar sem testes** → os clientes pagam por qualidade, testa sempre antes
5. **Não cobrar manutenção** → separar "criar" de "manter", cobrar mensalidade
