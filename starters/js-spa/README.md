# JS SPA Starter

Estrutura inicial para Single Page Applications em JavaScript puro, inspirada na arquitetura do PoupaPlus CRM.

## Características

- NPM + Vitest configurados
- Componentes reutilizáveis (Table, Modal, Filters)
- Lazy loading de módulos
- Store sync com backend (substituir Appwrite por REST API)
- Error handling + logging estruturados
- Testes unitários + E2E

## Setup

```bash
npm install
npm run dev   # Servir localmente
npm test      # Correr testes
```
